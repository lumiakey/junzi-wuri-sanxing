iPhone 侧 · 3 步配好

敲两下手机背面，它就自己开始录

配一次，往后全自动 —— 录完揣兜里，锁屏也不断。不用装任何 App，全靠系统自带。

✅ 动手前先确认：设置 → 你的 Apple ID → iCloud → 语音备忘录 已打开同步，否则 Mac 收不到录音。
1先建一个快捷指令30 秒搞定
快捷指令 App
右上角 ＋
添加操作 → 搜「语音备忘录」
选「创建录音」
命名 → 完成
存成 三省 · 开始录音，名字随意，下一步要选它。
💡有的版本里这个操作叫「录制音频」，效果一样。
2把「轻点背面」接上敲两下就录
设置
辅助功能
触控
轻点背面 → 轻点两下
选上一步那个指令
之后掏出手机敲两下背面，录音就开始，屏幕都不用点亮。
💡「轻点三下」可以再绑一个停止录音，一对儿用。
3加自动化让它不用你动手
快捷指令 → 自动化
＋ → 个人自动化
到达 / Wi-Fi / 时间
添加操作「创建录音」
关闭「运行前询问」
推荐三条一起开：到公司连上 Wi-Fi 开录、到家自动停、敲背面手动补录。
💡新系统里这个开关叫「立即运行」，一样要关掉询问。
⚠️ 坑 1iPhone 和 Mac 必须登录同一个 Apple ID，且都开着语音备忘录同步。
⚠️ 坑 2录音时手机会显示状态条，锁屏不影响录制，别去点停止。
⚠️ 坑 3录音涉及他人请遵守当地法律，涉密场合别录。
